# Sci-Hub 镜像接入功能 - 实施总结

## 概述

成功为墨知 Inkwise PDF 阅读器集成了 Sci-Hub 实时镜像功能，用户现在可以通过输入 DOI 号自动从多个来源获取学术论文 PDF。

## 实施的功能

### 1. 智能多源获取策略

系统按以下优先级自动尝试获取 PDF：

```
用户输入 DOI
    ↓
① 出版商官方网站（合法渠道优先）
    ↓ 失败
② Unpaywall 开放获取数据库（合法 OA 资源）
    ↓ 失败  
③ Sci-Hub 实时镜像（最后备选）
    ↓
成功 → 自动打开 PDF
失败 → 提示用户手动下载
```

### 2. Sci-Hub 实时镜像获取

#### 核心功能
- **自动获取镜像列表**：从 https://www.sci-hub.shop/ 实时抓取当前可用镜像
- **智能解析**：自动识别页面中的 sci-hub.se、sci-hub.st 等镜像地址
- **安全验证**：过滤不安全的内网地址和无效 URL
- **备用机制**：如果实时获取失败，使用预设的稳定镜像列表

#### 下载流程
```javascript
// 对每个镜像
1. 访问 {mirror}/{doi}
2. 解析页面获取 PDF 嵌入链接
   - 查找 iframe src
   - 查找直接下载链接
   - 查找按钮 onclick
3. 下载并验证 PDF
4. 验证文件头（%PDF）和大小
```

### 3. 安全防护

实施了多层安全防护：

- ✅ **DNS 验证**：防止 DNS 重绑定攻击
- ✅ **地址过滤**：拒绝访问内网地址（localhost, 192.168.x.x, 10.x.x.x 等）
- ✅ **协议限制**：仅允许 HTTP/HTTPS 协议
- ✅ **文件验证**：验证 PDF 文件头和 Content-Type
- ✅ **大小限制**：限制 PDF 文件最大 40MB
- ✅ **超时控制**：每个请求都有合理的超时时间
- ✅ **速率限制**：防止用户滥用服务

## 技术亮点

### 1. 实时镜像发现
不依赖硬编码的镜像列表，而是实时从 sci-hub.shop 获取最新可用镜像，适应 Sci-Hub 频繁更换域名的情况。

### 2. 智能 HTML 解析
支持多种 PDF 嵌入方式：
- `<iframe src="...">` - 最常见
- `<a href="...pdf">` - 直接链接
- `<button onclick="location.href='...'">` - 按钮跳转
- 相对路径、协议相对路径自动处理

### 3. 优雅降级
- 实时获取失败 → 使用预设镜像
- 单个镜像失败 → 自动尝试下一个
- 所有 Sci-Hub 失败 → 提供清晰的错误提示

### 4. 性能优化
- 设置合理的超时时间（8-15秒）
- 串行尝试镜像，避免过多并发连接
- 快速失败机制，不浪费用户等待时间

## 用户体验改进

### 使用前
```
输入 DOI → 
  出版商失败 → 
    Unpaywall 失败 → 
      ❌ 提示"无法获取"
```

### 使用后
```
输入 DOI → 
  出版商失败 → 
    Unpaywall 失败 → 
      Sci-Hub 镜像1 失败 → 
        Sci-Hub 镜像2 失败 → 
          Sci-Hub 镜像3 成功 → 
            ✅ 自动打开 PDF！
```

### 界面提示
- 导入对话框明确说明："DOI 解析会先尝试出版商官方渠道，再查询 Unpaywall 等开放获取资源，最后尝试 Sci-Hub 实时镜像。"
- 失败提示清晰："该 DOI 对应的 PDF 暂时无法获取。我们已尝试出版商官方渠道、Unpaywall 开放获取资源以及 Sci-Hub 镜像，但均未成功。"

## 合规性说明

### 法律考虑
- ⚖️ Sci-Hub 在某些地区存在法律争议
- ✅ 系统优先使用合法渠道（出版商、Unpaywall）
- ✅ Sci-Hub 仅作为最后备选
- ℹ️ 用户已被明确告知使用的来源

### 建议
1. 在用户协议中说明会使用第三方服务获取论文
2. 优先推广使用机构订阅和开放获取资源
3. 保留禁用 Sci-Hub 功能的选项（未来可配置）

## 性能指标

### 预期响应时间
- 出版商渠道：2-5 秒
- Unpaywall：3-8 秒
- Sci-Hub：5-15 秒（取决于镜像数量）
- 总体超时：30-40 秒

### 成功率预估
- 开放获取论文：90%+（Unpaywall）
- 付费论文：70-80%（Sci-Hub，取决于镜像可用性）
- 总体成功率：预计 80%+
