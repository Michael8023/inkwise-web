## 🔍 调试技巧

### 查看详细错误信息

1. 在 Chrome 中打开开发者工具（F12）
2. 切换到 "Console" 标签
3. 尝试导入 DOI
4. 查看控制台输出的详细错误信息

### 查看网络请求

1. 开发者工具 → "Network" 标签
2. 尝试导入 DOI
3. 查找对 `pdf-fetch` 的请求
4. 检查：
   - 请求头是否包含正确的 `Authorization` token
   - 响应状态码（200 成功 / 401 认证失败 / 400 其他错误）
   - 响应内容

### 常见问题排查

#### 问题 1: 一直显示 "无法读取该 PDF 链接"

**可能原因**:
- 缓存未清除，还在使用旧版本
- Session 确实已过期但未显示正确错误

**解决**:
```bash
# 1. 在 chrome://extensions/ 中，点击插件的"刷新"按钮
# 2. 硬刷新页面 (Ctrl+Shift+R)
# 3. 重新测试
```

#### 问题 2: 提示 "登录已过期"

**解决**:
1. 点击"退出登录"
2. 重新登录
3. 再次尝试导入 DOI

#### 问题 3: 加载时间过长（超过 30 秒）

**说明**:
- 这是正常的，尤其是使用 Sci-Hub 时
- 系统需要尝试多个镜像
- 如果超过 60 秒，可能是网络问题或所有镜像都不可用
